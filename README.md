# Adianta

Site demonstrativo para apresentação do TCC sobre a proposta conceitual de triagem digital e organização de atendimentos em repartições públicas.

## Como abrir

Abra `index.html` em um navegador atualizado. Para apresentar, use a navegação no topo ou role a página; em celular, o botão **Menu** abre os links das seções. A página se adapta a telas menores. A busca filtra os exemplos de serviços; o formulário permite escolher atendimento online ou presencial, com pedido demonstrativo de horário e senha.

Ao enviar a solicitação de atendimento online, o site abre `chat.html` em uma nova aba. O chat apresenta uma simulação interativa com respostas automáticas sobre serviços, documentação e agendamentos.

O site usa HTML, CSS e JavaScript sem dependências de instalação. As fontes DM Sans e Playfair Display são carregadas do Google Fonts quando há conexão; sem conexão, fontes locais de sistema serão usadas. Os links de consulta direcionam aos canais institucionais publicados.

O formulário salva os campos preenchidos e o resultado demonstrativo no armazenamento local do navegador, para reaparecer quando o site for aberto novamente no mesmo navegador e dispositivo. Os dados não são enviados a uma instituição ou a um servidor; limpar os dados do navegador remove esse cadastro. O site não agenda serviços nem envia notificações. A confirmação, o protocolo e a senha mostrados na tela são exemplos gerados no navegador. Use dados fictícios durante a apresentação. Os serviços, documentos exigidos, horários e modalidades disponíveis devem ser confirmados junto à instituição responsável.

## Personalização acadêmica

Na seção **Sobre o projeto**, substitua “Instituição de ensino · Curso · Autor(a) · Orientador(a) · Ano” pelos dados corretos. Referências bibliográficas não foram incluídas porque não foram fornecidas. O conteúdo apresenta a plataforma como proposta conceitual e preserva a ressalva de que ela complementa, sem substituir, o atendimento presencial ou os sistemas oficiais.
